# A/B Testing Analysis

## Overview
This project evaluates a product experiment by comparing a control group against a treatment group and measuring whether a change created a statistically significant lift in conversion rate.

## Problem
A product or marketing change can look promising from raw metrics, but without a proper test it is hard to separate real business impact from random variation. This project applies A/B testing methodology to make the decision evidence-based.

## What I Built
- Cleaned and validated the experimental dataset
- Compared control vs treatment conversion behavior
- Ran hypothesis testing and confidence interval analysis
- Measured effect size and practical significance
- Assessed power and business interpretation of the result

## Result
The final analysis showed that Variant B outperformed the control group:
- Conversion rate improvement: +2.7 percentage points
- p-value: 0.0234
- 95% confidence interval: [+0.8%, +4.6%]
- Decision: Variant B was the winner and should be adopted

This project demonstrates a full data-driven experimentation workflow from setup to recommendation.
